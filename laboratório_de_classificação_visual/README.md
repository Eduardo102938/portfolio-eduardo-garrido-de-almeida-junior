# 🚗 Classificação Visual com IA

Atividade prática utilizando o Teachable Machine para treinar um modelo de classificação visual e analisar erros causados pela limitação dos dados de treinamento.

---

# 🎯 Objetivo

Treinar um modelo de IA para identificar carros e motos e observar como a qualidade e quantidade de dados influenciam nos resultados.

---

# ⚙️ Desenvolvimento

Foi criado um sistema de classificação utilizando duas categorias:

- Carro
- Moto

O treinamento foi feito com imagens simples, utilizando poucos exemplos para cada categoria.

---

# ✅ Resultados

O sistema apresentou bons resultados:

- Identificando carros de frente;
- Identificando carros de trás;
- Identificando motos corretamente;
- Reconhecendo veículos com precisão satisfatória.

---

# ⚠️ Limitações

Mesmo funcionando bem, o sistema apresentou erros:

- Identificou humanos como carros;
- Identificou alguns objetos como motos;
- Mostrou falhas causadas pela pouca variedade de dados.

---

# 📚 Impacto

A atividade mostra como a IA consegue aprender rapidamente mesmo com poucas informações.

Porém, também evidencia que dados limitados geram interpretações erradas, fazendo o sistema classificar elementos que não pertencem às categorias treinadas.

Isso demonstra como a qualidade dos dados impacta diretamente no funcionamento da Inteligência Artificial.
