# 🧠 Batalha de Modelos — Engenharia de Prompt XML

Atividade prática de comparação entre diferentes IAs utilizando o mesmo prompt estruturado em XML para gerar uma página HTML Single Page com CSS integrado.

---

# 🎯 Objetivo

Avaliar como diferentes modelos de IA interpretam o mesmo prompt XML, observando:

- fidelidade às instruções;
- qualidade do HTML gerado;
- quantidade de tokens utilizados;
- erros e limitações de cada modelo.

---

# ⚙️ Desenvolvimento

Foi utilizado o mesmo prompt em XML para diferentes IAs:

- ChatGPT
- Gemini
- Claude
- Qwen
- DeepSeek
- Grok
- Maritaca

Cada IA gerou um código HTML com CSS integrado para uma página de loja de roupas.

---

# 📊 Resultados

Foram avaliados:

- precisão do HTML;
- criatividade;
- erros de sintaxe;
- consumo de tokens.

## Destaques

### Claude

- Melhor compreensão da estrutura XML;
- Código mais organizado;
- Interface bem construída;
- Mais adequado para projetos complexos.

### Qwen

- Código mais simples;
- Menor uso de tokens;
- Bom resultado para prototipagem rápida.

### Modelos com menor desempenho

- GPT;
- Maritaca.

Apresentaram:

- elementos misturados;
- imagens quebradas;
- layout genérico;
- menor aderência ao prompt.

---

# 📚 Reflexão Crítica

## Qual modelo demonstrou maior compreensão?

Claude demonstrou melhor interpretação do XML, entregando um HTML mais fiel e organizado.

---

## Houve diferença significativa nos tokens?

Sim.

Alguns modelos utilizaram poucos tokens, mas entregaram resultados simples.

Outros utilizaram mais tokens e geraram códigos mais completos.

---

## Melhor ferramenta para cada uso

### Prototipagem rápida

Qwen

### Códigos mais complexos

Claude

---

# 📌 Conclusão

A atividade mostrou que diferentes IAs respondem de forma muito distinta ao mesmo prompt.

Mesmo com a mesma instrução, o resultado varia bastante em qualidade, organização e fidelidade, mostrando a importância de escolher a ferramenta certa para cada tipo de tarefa.
