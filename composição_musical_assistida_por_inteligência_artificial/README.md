# 🎵 Projeto Música & IA — Kamaitachi

Projeto desenvolvido com Inteligência Artificial para criação de músicas originais inspiradas no estilo do artista Kamaitachi, utilizando Gemini Gems para composição e Suno AI para geração de áudio.

---

# 🎯 Objetivo

Explorar o uso de IA generativa para produção musical, utilizando modelos de linguagem para composição de letras e IA de áudio para criação das músicas completas.

---

# 🛠️ Ferramentas Utilizadas

- Gemini Gems
- Suno AI
- GitHub

---

# 🎤 Artista de Referência

Kamaitachi

Foram utilizadas letras do artista como base para treinar o Gems e reproduzir:

- estilo narrativo;
- métrica;
- ambientação;
- temática;
- construção melancólica e sombria.

---

# 🚀 Processo

## 1. Base de conhecimento

Foi criado um Gems personalizado alimentado com letras de referência do Kamaitachi para entender:

- escrita;
- vocabulário;
- construção de histórias;
- estética lírica.

---

## 2. Geração de letras

Foram criadas 5 músicas inéditas com temas novos:

- O Homem do Apartamento 307
- O Garoto que Conversava com Corvos
- A Casa no Fim da Rua
- Menina do Casaco Vermelho
- As Luzes da Cidade Nunca Dormem

---

## 3. Produção de áudio

Cada letra foi enviada ao Suno AI para gerar:

- voz;
- instrumental;
- ambientação;
- melodia.

# 📚 Conclusão

A atividade demonstrou como a IA pode auxiliar no processo criativo, permitindo gerar letras e músicas completas a partir de referências estilísticas.

Também mostrou que, mesmo reproduzindo padrões, a IA ainda depende de boas referências e ajustes humanos para alcançar resultados mais consistentes.
