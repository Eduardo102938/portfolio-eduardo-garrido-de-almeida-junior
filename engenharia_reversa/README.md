# 💻 Engenharia Reversa com IA

Atividade prática de reconstrução de um sistema utilizando Inteligência Artificial, analisando apenas a interface visual sem acesso ao código-fonte original.

---

# 🎯 Objetivo

Recriar um aplicativo funcional observando sua interface, lógica e comportamento, utilizando IA como apoio no desenvolvimento.

---

# ⚙️ Desenvolvimento

A atividade foi dividida em três etapas:

## 🔍 Análise

Foi acessado um sistema de referência para observar:

- interface;
- layout;
- funcionamento;
- regras de interação.

---

## ⚙️ Configuração

No Google AI Studio, a IA foi configurada para atuar como desenvolvedor Full-Stack.

Foram definidos:

- HTML;
- CSS;
- JavaScript;
- estrutura de arquivos;
- comportamento esperado.

---

## 🛠 Construção e Validação

A IA gerou o sistema.

Após isso:

- o código foi testado;
- comparado com o sistema original;
- refinado até se aproximar do comportamento esperado.

---

# 📚 Observações

Durante a atividade foi observado que:

- a IA gera muitos erros;
- quanto mais código é adicionado, mais falhas aparecem;
- em alguns casos o código se torna inutilizável;
- mesmo com comandos específicos, o resultado pode sair diferente.

Isso mostra que a IA é útil como apoio, mas não substitui totalmente o desenvolvedor.

---

# ❓ Reflexão 1

## Impacto na formação do desenvolvedor

O uso de IA muda o papel do programador júnior.

Competências necessárias:

- identificar erros gerados pela IA;
- saber corrigir código manualmente;
- descrever bem a lógica do sistema;
- validar resultados.

---

# ❓ Reflexão 2

## Quando vira plágio?

A engenharia reversa assistida por IA deixa de ser aprendizado quando o conteúdo copiado é utilizado no produto final sem autorização.

---

## Solução ética

Uma proposta:

- regulamentação da IA;
- documentos de autoria;
- uso liberado para estudos;
- restrição para uso comercial sem permissão.
